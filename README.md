# Epson USB Print (Android)

تطبيق أندرويد (Kotlin) للطباعة عبر USB مع Epson Stylus SX130.

## ماذا يعمل حالياً

- كشف الطابعة Epson عند توصيلها بكابل USB (OTG) وطلب صلاحية الوصول.
- قراءة حالة الطابعة (متصلة / الورق / خطأ) وقراءة **Device ID**.
- فتح PDF أو صورة، أو كتابة نص (يدعم العربية)، مع **معاينة صفحة بصفحة** بحجم A4.
- زر «طباعة عبر نظام أندرويد» (PrintManager) لإرسال الصفحات إلى خدمة طباعة مثبّتة على الهاتف.

## ما لم يكتمل

زر «إرسال مباشر عبر USB» يرسل بايتات إلى الطابعة، لكن **مرمّز بروتوكول Epson** (ملف `RasterJobEncoder.kt`) غير منفَّذ.
الـ SX130 لا تفهم PDF ولا نصاً عادياً: تحتاج Raster بلغة Epson الخاصة. هذا الجزء لم يُختبر ولا يمكن
اختباره دون الطابعة نفسها.

## خطوات التشغيل

1. افتح المجلد في Android Studio ووافق على Gradle Sync (وعلى إنشاء Gradle wrapper إن طُلب).
2. شغّل التطبيق على هاتف يدعم USB OTG (وليس المحاكي).
3. وصّل الطابعة بكابل OTG، شغّلها، ثم اضغط «كشف الطابعة / فحص» واسمح بالصلاحية.
4. **أرسل لي نص `Device ID` الظاهر** (خاصة حقل `CMD:`) لأعرف لغة الطباعة الفعلية وأكمل المرمّز.

## الملفات

| الملف | الدور |
|---|---|
| `UsbPrinter.kt` | كشف الطابعة، الصلاحية، الحالة، إرسال Bulk |
| `DocumentRenderer.kt` | PDF / صورة / نص إلى صفحات A4 |
| `BitmapPrintAdapter.kt` | الطباعة عبر نظام أندرويد |
| `RasterJobEncoder.kt` | واجهة مرمّز Epson (غير منفَّذ) |
| `MainActivity.kt` | الواجهة |
